
# Movie Ticketing System

This repository contains the Software Requirements Specification (SRS) and software design documentation for a web-based movie ticketing system.

## Overview

The system is designed to help customers browse movies, view showtimes, select seats, purchase tickets, and manage reservations. Administrators can manage movies, showtimes, seat availability, and ticket information.

## Main Features

- Movie and showtime browsing
- Real-time seat availability
- Seat selection and reservation
- Ticket purchasing and payment processing
- Unique ticket ID generation
- Customer ticket cancellation
- Administrator management tools

## Documentation Includes

- Functional and non-functional requirements
- Customer and administrator use cases
- Database requirements
- UML, sequence, data-flow, and state-transition models
- Performance, security, reliability, and availability requirements
- Change-management process

## Project Context

This was developed as a collaborative software systems design project. The documentation represents the planning and design phase of the system before implementation.
